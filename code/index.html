DEV NOTE / 001
Why the hook belongs to the intent.
Liquidity fragments across launchpads, AMMs and routers. A pool-local hook cannot describe a user’s complete route. Jolt Guard therefore treats the signed transaction as the enforcement boundary: snapshot balances, run the route, reload state, enforce the promised result, then commit or revert atomically.

DEV NOTE / 002
Why realized balance deltas are the source of truth.
Quotes and simulations describe expected execution. Settlement conditions must inspect the state that actually changed. Jolt Guard snapshots the source and destination token accounts, executes the route, reloads both accounts and performs checked integer comparisons against the signed limits.
