# Joltwork

A proposed Solana-native settlement transparency layer.

Joltwork applies the disclosure problem documented in An Empirical Study of Undisclosed Charges in Hook-Based Decentralized Exchanges to Solana's execution model. The frontend presents a research prototype: preflight simulation, CPI-path reconstruction, Token-2022 extension awareness, pre/post balance reconciliation, and an itemized receipt.

This is a concept, not a deployed mainnet program. Page statistics are identified as the paper's Ethereum/BSC research baseline, not Solana measurements.

Research: https://arxiv.org/abs/2610.36682
