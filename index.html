01 / the gap

A quote is a promise.
A receipt is evidence.

The paper shows that a trader can receive exactly the quoted output while an additional settlement deduction remains absent from the fee breakdown. Joltwork carries that lesson to Solana: compare the interface claim, simulated execution and confirmed account deltas—then name every difference.

02 / architecture

Reconstruct the route,
not just the result.

Solana exposes the raw material for a defensible receipt: transaction messages, address lookup tables, CPI traces, logs, lamport balances, and pre/post token balances. Joltwork joins those fragments into one settlement graph.

01 / DECODE

Issue receipt

03 / solana surface

Different runtime.
Same disclosure problem.

Solana is not Uniswap v4. Joltwork follows Solana's actual execution surface instead of pretending EVM rules transfer one-to-one.

CPI TREE

Program-directed movement

Inner instructions reveal which router, pool, token program or custom program caused a balance change.

TOKEN-2022

Transfer fees

Configured transfer fees reduce received amounts and accumulate withheld value. They are listed separately from DEX fees.

TRANSFER HOOK

Custom transfer logic

A mint can invoke a configured program on every transfer. Joltwork fingerprints the program and its extra accounts.

PROGRAM STATE

Rules can move

Routes, authorities and upgradeable programs change. Findings bind to a slot, signature and observed state.

04 / receipt format

Readable by a wallet.
Auditable by anyone.

The output is not a black-box risk score. It is a compact claim backed by transaction evidence: what was expected, what moved, which program moved it, and what remains unresolved.
